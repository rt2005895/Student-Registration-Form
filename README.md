# Student Registration Form

## About the Project
A simple student registration form developed using HTML5 and CSS3. It collects basic student information, including personal details, gender, date of birth, address, department, course, and challan file.

## Technologies Used
- HTML5
- CSS3

## Features
- Student personal information fields
- Gender selection
- Date of birth input
- Blood group dropdown
- Department and course selection
- Challan file upload field
- Submit and Reset buttons
- Gradient background and styled form layout

## Project Structure

Student-Registration-Form/
├── index.html
├── style.css

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Disclaimer
This project is created for educational purposes only. It is a basic frontend form and does not store or process student information.
